# HelpDesk Lab

## Overview
This project simulates common IT Help Desk support scenarios to demonstrate troubleshooting and user support skills.

## Skills Demonstrated
- Troubleshooting Windows issues
- Password resets and user support
- Basic network diagnostics
- Identifying and resolving common system problems

## Tools Used
- Windows Operating System
- Virtual Machines
- Help Desk troubleshooting methodology

## Purpose
This lab was created to practice real-world IT support tasks commonly performed by 1st Line / Service Desk technicians.
